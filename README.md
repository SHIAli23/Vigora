# Vigora

## Публикуване онлайн

Vigora се публикува като едно Docker приложение (API + трите уеб приложения) и една база данни
PostgreSQL. Стъпките по-долу използват безплатните услуги на [Render](https://render.com).

### 1. База данни

1. Влезте в [render.com](https://render.com) с акаунта си в GitHub.
2. **New → Postgres**.
3. Име: `vigora-db`, регион: **Frankfurt (EU Central)**, план: **Free**. Натиснете **Create Database**.
4. Когато базата е готова, копирайте **Internal Database URL** от страницата ѝ.

### 2. Уеб услуга

1. **New → Web Service** и изберете GitHub хранилището на Vigora.
2. Настройки:
   - **Language:** Docker (Render намира `Dockerfile` в корена сам)
   - **Branch:** `main`
   - **Region:** същият като на базата (**Frankfurt**), за да работи вътрешният адрес
   - **Instance Type:** Free
3. В **Environment Variables** добавете:

   | Променлива | Стойност |
   |---|---|
   | `DATABASE_URL` | Internal Database URL от стъпка 1 |
   | `SECRET_KEY` | дълъг случаен текст, поне 32 знака (бутонът **Generate** на Render върши работа) |
   | `SEED_DEMO_DATA` | `true` |

   `PORT` не се задава — Render го подава сам. Адрес от вида `postgres://…` или `postgresql://…`
   се превръща автоматично в `postgresql+psycopg://…`.

   Друг начин да създадете `SECRET_KEY`:

   ```
   python -c "import secrets; print(secrets.token_urlsafe(48))"
   ```

4. В **Advanced → Health Check Path** въведете `/health`.
5. Натиснете **Deploy Web Service**. Първото публикуване отнема няколко минути.
   След всяко ново `push` в `main` Render публикува отново сам.

### 3. Проверка

Приложението е на адрес от вида `https://vigora-xxxx.onrender.com`:

| Страница | Адрес |
|---|---|
| Начална страница | `/` |
| Граждани | `/citizen/` |
| Оператор 112 | `/operator/` |
| Екипи | `/team/` |
| API документация | `/docs` |

### Тестови акаунти

При `SEED_DEMO_DATA=true` те се създават при първото стартиране с празна база.

| Роля | Потребителско име | Парола |
|---|---|---|
| Оператор 112 | `operator` | `operator123` |
| Граждани | `citizen1` … `citizen5` | `citizen123` |
| Екипи | `med1`, `med2`, `fire1`, `fire2`, `police1`, `police2` | `team123` |

### Важно

- **HTTPS е задължителен за GPS на телефона.** Браузърите дават местоположение само на сайтове с
  `https://` (или на `localhost`). Render дава HTTPS автоматично, а приложенията сами използват
  `wss://` за връзката в реално време. Затова на телефон отваряйте адреса с `https://`, не IP адрес
  в локалната мрежа.
- **Безплатната услуга „заспива“** след около 15 минути без посещения и първото отваряне след това
  отнема до минута. Отворете сайта малко преди представянето.
- **Снимките се пазят на диска на услугата** и се губят при ново публикуване или рестарт.
  Сигналите, акаунтите и екипите са в базата и остават.
- **Безплатната база на Render е с ограничен срок.** Проверете датата на изтичане в Render и
  създайте нова база преди нея, ако е нужно.

### Локална проверка на образа

```
docker build -t vigora .
docker run --rm -p 8000:8000 -e DATABASE_URL=sqlite:///./vigora.db vigora
```

След това отворете http://localhost:8000.
